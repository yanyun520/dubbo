# Dubbo 核心流程可视化说明

## 1. 服务暴露流程 (Provider Export)

```
┌───────────────────────────────────────────────────────────────┐
│                   ServiceConfig.export()                        │
│    用户配置服务并调用export()方法                              │
└───────────────────────┬─────────────────────────────────────────┘
                        │
        ┌───────────────▼──────────────────┐
        │   1. 验证配置                     │
        │   - 检查必要参数                  │
        │   - 生成URL                       │
        └───────────────┬──────────────────┘
                        │
        ┌───────────────▼──────────────────────────────┐
        │   2. 构建本地Invoker                         │
        │   - ProxyFactory.getInvoker()                │
        │   - 包装用户的服务实现                      │
        └───────────────┬──────────────────────────────┘
                        │
        ┌───────────────▼──────────────────────────────┐
        │   3. 应用Provider Filter链                   │
        │   - ContextFilter  (上下文)                  │
        │   - ValidationFilter (验证)                  │
        │   - TimeoutFilter (超时)                     │
        │   - ...                                      │
        └───────────────┬──────────────────────────────┘
                        │
        ┌───────────────▼──────────────────────────────┐
        │   4. Protocol.export(wrappedInvoker)         │
        │   - 根据配置的协议(triple/dubbo等)         │
        │   - 创建Exporter对象                         │
        └───────────────┬──────────────────────────────┘
                        │
        ┌───────────────▼──────────────────────────────┐
        │   5. Registry.register()                     │
        │   - 向注册中心注册服务URL                    │
        │   - 如: dubbo://ip:port/service?params     │
        └───────────────┬──────────────────────────────┘
                        │
        ┌───────────────▼──────────────────────────────┐
        │   6. 启动网络监听                            │
        │   - Netty Server启动                         │
        │   - 监听指定端口                            │
        │   - 等待请求                                │
        └───────────────┬──────────────────────────────┘
                        │
                        ▼
            ┌──────────────────────┐
            │  服务暴露完成          │
            │ ✓ 返回Exporter对象    │
            └──────────────────────┘
```

## 2. 服务引用流程 (Consumer Refer)

```
┌───────────────────────────────────────────────────────────────┐
│                 ReferenceConfig.get()                          │
│        用户配置服务引用并调用get()获取代理                     │
└───────────────────────┬─────────────────────────────────────────┘
                        │
        ┌───────────────▼──────────────────────────┐
        │   1. 验证配置                            │
        │   - 检查接口和必要参数                   │
        │   - 构建服务引用URL                      │
        └───────────────┬──────────────────────────┘
                        │
        ┌───────────────▼──────────────────────────┐
        │   2. Registry.subscribe()                │
        │   - 向注册中心订阅该服务                 │
        │   - 监听服务提供者变化                   │
        └───────────────┬──────────────────────────┘
                        │
        ┌───────────────▼──────────────────────────┐
        │   3. RegistryDirectory处理               │
        │   - 获取所有可用的服务提供者URL         │
        │   - 为每个提供者创建Invoker             │
        └───────────────┬──────────────────────────┘
                        │
        ┌───────────────▼──────────────────────────┐
        │   4. 创建ClusterInvoker                  │
        │   - 包装Directory                        │
        │   - 支持多个提供者                       │
        └───────────────┬──────────────────────────┘
                        │
        ┌───────────────▼──────────────────────────┐
        │   5. 应用Consumer Filter链               │
        │   - ContextFilter (上下文)               │
        │   - MonitorFilter (监控)                 │
        │   - ValidationFilter (验证)              │
        │   - ...                                  │
        └───────────────┬──────────────────────────┘
                        │
        ┌───────────────▼──────────────────────────┐
        │   6. ProxyFactory.getProxy()             │
        │   - 创建服务接口的代理对象              │
        │   - 通过Javassist或ByteBuddy            │
        └───────────────┬──────────────────────────┘
                        │
                        ▼
        ┌──────────────────────────┐
        │  返回代理对象给用户       │
        │ ✓ 用户可直接调用方法     │
        └──────────────────────────┘
```

## 3. 一次RPC调用的完整流程

```
┌─ CONSUMER 端 ────────────────────────────────────────────────────────┐
│                                                                        │
│  1. 用户代码调用
│     service.sayHello("world")
│                  │
│                  ▼
│  2. 代理类拦截 (Proxy interceptor)
│     ├─ 提取方法信息 (method, args)
│     ├─ 构建Invocation对象
│     │  ├─ interfaceName
│     │  ├─ methodName
│     │  ├─ parameterTypes
│     │  ├─ arguments: ["world"]
│     │  └─ attachments: {...}
│     └─ 传递给Invoker
│                  │
│                  ▼
│  3. Consumer Filter链处理 (入向)
│     ├─ ContextFilter
│     │  └─ RpcContext.setContext()
│     ├─ MonitorFilter  (可选)
│     │  └─ 记录调用开始
│     ├─ ValidationFilter
│     │  └─ 验证参数
│     └─ 其他Filter...
│                  │
│                  ▼
│  4. ClusterInvoker处理
│     ├─ Directory.list()
│     │  └─ 获取所有可用提供者 [invoker1, invoker2, ...]
│     ├─ Router过滤
│     │  └─ 应用路由规则筛选
│     ├─ LoadBalance选择
│     │  └─ 从可用列表中选择一个: invoker2
│     └─ 调用选中的Invoker
│                  │
│                  ▼
│  5. ProtocolInvoker (通常是TripleInvoker/DubboInvoker)
│     ├─ 序列化参数
│     │  └─ Serialization.serialize()
│     ├─ 构建请求消息
│     │  ├─ Request Header (协议头)
│     │  ├─ Service Interface
│     │  ├─ Method
│     │  └─ Arguments
│     └─ 获取或创建连接
│                  │
│                  ▼
│  6. Transport层发送
│     ├─ Codec编码消息
│     ├─ Channel.send()
│     ├─ Netty客户端发送
│     └─ 等待响应 (CompletableFuture)
│                  │
└────────────────────────┼──────────────────────────────────────────────┘
                         │
                   [网络传输]
                         │
┌────────────────────────▼────────────────────────────────────────────┐
│ PROVIDER 端                                                           │
│                                                                       │
│  1. Server接收请求
│     ├─ ChannelHandler捕获事件
│     └─ 消息事件: RECEIVED
│                  │
│                  ▼
│  2. Codec解码
│     ├─ 解析协议头
│     ├─ 验证魔数、版本
│     ├─ 提取serialization ID
│     └─ 反序列化参数
│                  │
│                  ▼
│  3. 构建Invocation
│     ├─ 提取方法名、参数
│     ├─ 设置attachments
│     └─ 传递给Handler
│                  │
│                  ▼
│  4. Provider Filter链处理 (入向)
│     ├─ ContextFilter
│     │  └─ RpcContext.setContext()
│     ├─ ValidationFilter
│     │  └─ 参数合法性检查
│     ├─ AuthorizationFilter (可选)
│     │  └─ 权限校验
│     └─ 用户自定义Filter
│                  │
│                  ▼
│  5. 本地Invoker执行
│     ├─ DelegateProviderMetaDataInvoker
│     ├─ 反射调用: serviceImpl.sayHello("world")
│     ├─ 业务逻辑执行
│     └─ 获得返回值: "hello, world"
│                  │
│                  ▼
│  6. 构建Response
│     ├─ 包装返回值到Result
│     ├─ 处理异常 (如果有)
│     └─ 添加响应头
│                  │
│                  ▼
│  7. Provider Filter链处理 (出向)
│     ├─ ContextFilter (清理)
│     ├─ ValidationFilter (出向处理)
│     └─ 其他Filter (出向)
│                  │
│                  ▼
│  8. 序列化响应
│     ├─ Serialization.serialize()
│     ├─ 返回值序列化: "hello, world"
│     └─ 构建响应消息
│                  │
│                  ▼
│  9. Transport发送响应
│     ├─ Codec编码
│     ├─ Channel.send()
│     └─ 通过Netty发送
│                  │
└────────────────────────┼──────────────────────────────────────────┘
                         │
                   [网络传输]
                         │
┌────────────────────────▼──────────────────────────────────────────┐
│ CONSUMER 端 - 响应处理                                             │
│                                                                    │
│  1. 接收响应消息
│     └─ CompletableFuture收到响应
│                  │
│                  ▼
│  2. Codec解码响应
│     ├─ 解析协议头
│     ├─ 反序列化响应数据
│     └─ 创建Result对象
│                  │
│                  ▼
│  3. Consumer Filter链处理 (出向)
│     ├─ ContextFilter (清理)
│     ├─ MonitorFilter (记录完成)
│     ├─ ValidationFilter (响应验证)
│     └─ 其他Filter
│                  │
│                  ▼
│  4. 返回给代理
│     ├─ 提取返回值
│     ├─ 如有异常则抛出
│     └─ 返回结果给用户代码
│                  │
│                  ▼
│  用户获得返回值: result = "hello, world"
│
└────────────────────────────────────────────────────────────────────┘
```

## 4. SPI加载机制流程

```
┌──────────────────────────────────────────────────────────────┐
│  ExtensionLoader.getExtension("myloadbalance")               │
└─────────────────────┬────────────────────────────────────────┘
                      │
          ┌───────────▼──────────┐
          │  1. 检查缓存          │
          │  ✓ 找到 → 返回       │
          │  ✗ 未找到 → 继续    │
          └───────────┬──────────┘
                      │
          ┌───────────▼──────────────────────┐
          │  2. 加载配置文件                 │
          │  从META-INF/dubbo/internal/     │
          │  读取: LoadBalance文件           │
          │  格式: name=ClassName            │
          └───────────┬──────────────────────┘
                      │
          ┌───────────▼──────────────────────┐
          │  3. 获取实现类                   │
          │  clazz = Class.forName(className)│
          └───────────┬──────────────────────┘
                      │
          ┌───────────▼──────────────────────┐
          │  4. 创建实例                     │
          │  instance = clazz.newInstance()  │
          └───────────┬──────────────────────┘
                      │
          ┌───────────▼──────────────────────┐
          │  5. 自动依赖注入                 │
          │  - 扫描setter方法                │
          │  - 识别@Extension标记的参数     │
          │  - 递归加载依赖                  │
          └───────────┬──────────────────────┘
                      │
          ┌───────────▼──────────────────────┐
          │  6. 应用Wrapper包装              │
          │  - 查找@Wrapper标记的类         │
          │  - 按顺序包装instance           │
          │  - 支持AOP增强                  │
          └───────────┬──────────────────────┘
                      │
          ┌───────────▼──────────────────────┐
          │  7. 缓存并返回                   │
          │  extensionInstances.put(clazz)   │
          │  返回最终的实例                  │
          └───────────┬──────────────────────┘
                      │
                      ▼
          返回(可能被Wrapper)的实现类实例
```

## 5. 配置层级和优先级

```
┌─────────────────────────────────────────────┐
│  配置优先级 (从高到低)                      │
└─────────────────────────────────────────────┘

    优先级高
       ▲
       │
       │  ┌────────────────────────────────┐
       │  │ 1. 方法级别参数配置            │  最高
       │  │    (MethodConfig)              │
       │  └────────────────────────────────┘
       │
       │  ┌────────────────────────────────┐
       │  │ 2. 参数级别配置                │
       │  │    (ArgumentConfig)            │
       │  └────────────────────────────────┘
       │
       │  ┌────────────────────────────────┐
       │  │ 3. 服务级别配置                │
       │  │    (ServiceConfig/ReferenceConfig) │
       │  └────────────────────────────────┘
       │
       │  ┌────────────────────────────────┐
       │  │ 4. 运行时动态配置              │
       │  │    (ConfigCenter下发)          │
       │  └────────────────────────────────┘
       │
       │  ┌────────────────────────────────┐
       │  │ 5. 全局应用配置                │
       │  │    (ApplicationConfig)         │
       │  └────────────────────────────────┘
       │
       │  ┌────────────────────────────────┐
       │  │ 6. 协议级别配置                │
       │  │    (ProtocolConfig)            │
       │  └────────────────────────────────┘
       │
       │  ┌────────────────────────────────┐
       │  │ 7. 系统属性和环境变量          │
       │  │    (System Properties)         │
       │  └────────────────────────────────┘
       │
       │  ┌────────────────────────────────┐
       │  │ 8. 代码默认值                  │
       │  │    (Default Value)             │
       │  └────────────────────────────────┘
       ▼
    优先级低

优先级高的配置会覆盖优先级低的配置
```

## 7. Filter链执行顺序

```
Consumer Filter Chain:
═════════════════════════════════════════════════

入向 (Request)
──────────────────────────────────────────────────
用户代码
    ↓
代理调用
    ↓
[入向Filter] ContextFilter (RpcContext设置)
    ↓
[入向Filter] MonitorFilter (监控开始)
    ↓
[入向Filter] TimeoutFilter (超时控制)
    ↓
[入向Filter] ValidationFilter (验证)
    ↓
[入向Filter] 自定义Filter
    ↓
Cluster (路由&负载均衡)
    ↓
发送到Provider


出向 (Response)
──────────────────────────────────────────────────
收到Provider响应
    ↓
[出向Filter] 自定义Filter (反向)
    ↓
[出向Filter] ValidationFilter (反向)
    ↓
[出向Filter] TimeoutFilter (反向)
    ↓
[出向Filter] MonitorFilter (监控结束)
    ↓
[出向Filter] ContextFilter (清理)
    ↓
返回结果给用户代码


Provider Filter Chain:
═════════════════════════════════════════════════

入向 (Request处理)
──────────────────────────────────────────────────
收到Consumer请求
    ↓
解码请求
    ↓
[入向Filter] ContextFilter (RpcContext设置)
    ↓
[入向Filter] ValidationFilter (验证)
    ↓
[入向Filter] AuthorizationFilter (身份验证)
    ↓
[入向Filter] 自定义Filter
    ↓
本地业务Invoker执行
    ↓
业务逻辑处理
    ↓

出向 (Response返回)
──────────────────────────────────────────────────
[出向Filter] 自定义Filter (反向)
    ↓
[出向Filter] AuthorizationFilter (反向)
    ↓
[出向Filter] ValidationFilter (反向)
    ↓
[出向Filter] ContextFilter (清理)
    ↓
编码响应
    ↓
发送给Consumer
```
